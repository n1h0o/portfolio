# «Свод» — база знаний с ИИ-помощником

Готовое демонстрационное веб-приложение для поиска по рабочей библиотеке. Включает локальный фильтр, карточки документов, диалог помощника с подсказанными источниками и локальное добавление примера документа. ИИ-модель, backend, хранение и внешние запросы не подключены; все документы вымышлены.

Исходники и запуск: [`source/README.md`](source/README.md). [Исследование и дизайн](docs/design.md).

Публичный репозиторий: https://github.com/n1h0o/team-knowledge-base
