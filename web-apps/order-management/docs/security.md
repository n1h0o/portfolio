# Безопасность и границы данных

- Используются синтетические имена, телефоны, адреса и товары; не вводите реальные персональные данные.
- Приложение не отправляет формы во внешнюю сеть. Google Fonts загружаются из Google Fonts и могут раскрывать сетевому поставщику стандартные метаданные запроса браузера.
- Интерфейс не аутентифицирует пользователя и не хранит данные между перезагрузками. Не используйте его для настоящих заказов.
- React экранирует текстовые значения при отображении; пользовательские строки не интерпретируются как HTML.
- Любая будущая интеграция с backend потребует серверной авторизации, проверки доступа к заказу и валидации входных данных.
