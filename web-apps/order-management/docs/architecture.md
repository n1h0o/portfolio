# Архитектура

React 19 + TypeScript + Vite, один экран и локальный компонентный интерфейс. `App.tsx` содержит демонстрационную модель заказов, фильтрацию, действия и локальную форму. Стили разделены на глобальные токены и компоненты. Сервер, маршрутизация, база данных и внешние API не требуются для заявленного локального сценария.

Данные живут в состоянии React и сбрасываются при перезагрузке. При подключении реального хранения потребуется отдельная модель с правами доступа, журналированием изменений и миграциями; демонстрационная модель не является контрактом backend API.
