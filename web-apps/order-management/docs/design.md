# Дизайн-система «Поток»

## Reference lock
- **Основное направление:** Replay, его светлый редакционный тон, графитовая типографика, тонкие разделители и сдержанный ритм.
- **Заимствовано:** у Orderful — операционная плотность данных и единая геометрия; у Replay — редкий акцент и лёгкие панели.
- **Собственная адаптация:** лайм `#D4FF39` обозначает основное действие. Он используется на кнопке добавления, выбранной очереди и текущем этапе. Не используется в длинном тексте.
- **Поверхности:** фон `#F4F4F0`, панели `#FFFFFF`, строки `#FAFAF8`, линии `#E6E6DF`.
- **Типографика:** Manrope для интерфейса, DM Mono для идентификаторов, временных отметок и служебных меток. Основной текст 10–14 px, заголовок 33 px.
- **Геометрия:** карточки 8 px, кнопки/поля 5–6 px, сетка с шагом 4/8 px, мягкая тень только у боковой карточки и модального окна.
- **Состояния:** статусы различаются оттенками и текстовыми метками, поэтому цвет не является единственным носителем значения.
- **Адаптивность:** на компактной ширине навигация сворачивается, фильтры прокручиваются, таблица получает локальную прокрутку, страница и карточки остаются внутри экрана.

## Решения
| Решение | Источник | Зачем |
|---|---|---|
| Светлая рабочая ведомость | Replay; необходимость отличить от «Сектора» | Быстро читать очередь при длительной работе |
| Один лаймовый цвет для действия | Принцип редкого акцента из Replay и Orderful, собственный цвет | Связать «создать» и «двигать этап» с действием без красного сигнала ошибки |
| Таблица + карточка заказа | Требования сценариев | Сохраняет обзор и даёт место подробностям без перегруза списка |
| Manrope + DM Mono | Отказ от шрифтов Refero и типографик существующих кейсов | Разделить чтение и операционные коды |
| Статусные текстовые чипы | Доступность и читаемость | Этап понятен без распознавания оттенка |
