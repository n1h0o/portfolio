# Исследование визуальных референсов

Дата: 26.10.2026.

## Refero
MCP Refero вернул `NO_SUBSCRIPTION`. Для резервного исследования открыт каталог [styles.refero.design](https://styles.refero.design/?q=CRM+lead+management+sales+workspace), найден и изучен полный стиль [Relate](https://styles.refero.design/style/337ade6a-4bae-49ba-b4aa-8994ac805a81).

## Наблюдения и выбор
Relate сочетает холодно-белую поверхность, тёмные заголовки, насыщенный синий акцент, светлый лавандово-голубой фон, цветные статусы и компактную типографику. Из референса взяты только ясная иерархия воронки и дисциплина одного активного синего; значения токенов и компоновка переосмыслены для «Круга». Сделана плотная рабочая канбан-поверхность с пятью стадиями, локальными фильтрами и карточкой контекста.

## Ограничения
Референс является источником визуального направления, а не источником компонентов. Чужие графические материалы и код не копировались. Продуктовые записи «Круга» придуманы.
