# «Круг» — CRM для обработки заявок

**Статус:** готовое демонстрационное веб-приложение.

CRM для небольшой команды продаж включает канбан-воронку, табличный список, фильтры, локальный поиск, карточку сделки с заметкой, контроль заявок без касания и добавление лидов в текущую сессию. Интерфейс адаптирован для телефона и компьютера.

Все контакты и компании синтетические. Данные существуют только в памяти вкладки и не отправляются внешним сервисам. Backend и реальные подключения не включены.
