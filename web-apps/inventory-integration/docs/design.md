# Дизайн-система — «Сектор»

## Reference lock
- **Источник:** Panxo, Refero Styles — data terminal, метрики, акцентные клетки, функциональная плотность.
- **Переносим:** табличную ясность, маркированные данные, визуально быстрый сигнал об ошибке.
- **Отклоняем:** тёплую кремовую поверхность и цветовую подсветку из референса; не используем лендинг и рекламные визуалы.

## Система
- Основа `#211B29`, поверхности `#2A2333` и `#332B3D`, текст `#F1ECF3`, вторичный `#AA9EAF`, границы `#463A50`.
- Коралловый `#FF866C` отмечает действие/расхождение; мятный `#A8D8C2` — синхронизированное состояние; цвет не означает реальную связь с API.
- IBM Plex Sans для интерфейса, IBM Plex Mono для SKU, колонок и технических отметок.
- Горизонтальный заголовок и обзор над плотной инвентаризационной таблицей. Без CRM-воронки или карточного дашборда.
- Технический локальный журнал событий связывает складские изменения с последующими расхождениями.

## Доступность
Семантические формы и кнопки, подписанные метки, фокус-кольцо, модалка с Escape и удержанием фокуса. Таблица имеет локальную область прокрутки на узком экране; отступы и фильтр сохраняют работу с телефоном. Поддержан `prefers-reduced-motion`.
