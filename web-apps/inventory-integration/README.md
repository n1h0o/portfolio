# «Сектор» — складская система с интеграцией торговых каналов

**Статус:** готовая демонстрационная система.

Локальная панель показывает физический склад, резервы, доступное число единиц, опубликованные количества по собственному сайту и маркетплейсам. Включает поиск, фильтры, CSV-отчёт, ручную складскую корректировку, новые SKU, локальную сверку, исправление публикаций и журнал.

Реальных интеграций нет: любые изменения — только в открытой вкладке. Модель не связывается с 1С, интернет-магазинами или маркетплейсами.
