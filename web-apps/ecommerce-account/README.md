# «Прибой» — интернет-магазин и личный кабинет

**Статус:** готовый демонстрационный e-commerce продукт.

Каталог авторской керамики с карточками изделий, поиском и категориями, сортировкой, избранным, корзиной, демо-скидкой, checkout и личным кабинетом с историей заказа. Оригинальная фотосессия сгенерирована для каталога.

Покупка полностью локальная: платежей и отправки данных нет. Товары, аккаунт и заказ вымышлены; изменения существуют только пока вкладка открыта.
