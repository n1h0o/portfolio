# Сайт кафе и ресторана «ДЕНЬ»

**Статус:** полноценный продукт сайта для кафе и ресторана.
**Рынок:** СНГ; русский язык по умолчанию, настройки страны/города, языка, валюты и контактов.
**Публичный репозиторий исходного кода:** https://github.com/n1h0o/cafe-restaurant-site

Одностраничный сайт с интерактивным меню, категориями, фильтрами состава, бронированием столика, контактной информацией и адаптивной навигацией. Содержит законченный проект студии и демонстрационные данные для показа покупателю; все данные ресторана редактируются отдельно.
