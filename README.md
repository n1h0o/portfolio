# Портфолио студии

Каталог готовых цифровых продуктов студии и материалов для их публикации на сайте-визитке.

## Структура

- `studio-site/` — собственный сайт-визитка студии.
- `sites/` — демонстрационные сайты.
- `web-apps/` — коммерческие веб-приложения.
- `telegram-bots/` — Telegram-боты.
- `ai-agents/` — ИИ-агенты.

Каждый продукт получает собственную папку. В папке продукта хранятся описание проекта и подготовленные материалы кейса. Исходный код разрабатывается в отдельном публичном репозитории проекта и ссылается из файла `README.md` внутри этой папки. Так проекты остаются независимыми, а каталог собирает материалы для сайта студии.

Папки будущих проектов являются только структурой каталога, а не готовыми продуктами или опубликованными кейсами. Наполнять сайт можно после фактической реализации и проверки продукта.

## Статус

- Сайт-визитка студии — готов, [исходный репозиторий](https://github.com/n1h0o/studio-vizitka).
- Следующая группа после завершения сайта-визитки — демонстрационные сайты.
