# Правила каталога портфолио

- Каждый продукт ведётся в своей папке. Исходный код проекта — в отдельном публичном репозитории, созданном для этого проекта; ссылка хранится в README его папки.
- Создавай и изменяй только репозитории, созданные для проектов студии. Личные репозитории владельца можно только просматривать.
- Не удаляй и не очищай репозитории, ветки, историю, базы данных или их содержимое.
- Не публикуй незавершённый продукт как готовый кейс на сайте. Папки со статусом «В плане» — только каталог будущих работ.
- По требованию владельца создавай законченный продукт в согласованном объёме; не сдавай прототипы, тестовые варианты или неполные заглушки. Проверки и аудит качества обязательны для готового продукта.
- Добавляй материалы кейса после фактической реализации и проверки; не выдумывай клиентов, метрики, отзывы или результаты.
- Каждый сайт и веб-приложение должен иметь собственную визуальную идентичность: отличающиеся палитру, стилистику и шрифтовую систему. Не переиспользуй один и тот же шаблон для разных продуктов; изучай подходящие референсы и проектируй оформление под конкретный продукт и его аудиторию.
- Каждый Telegram-бот и ИИ-агент должен отличаться назначением и функциональностью. Не тиражируй один и тот же сценарий или набор возможностей под разными названиями; формируй функциональность под задачу конкретного продукта.
